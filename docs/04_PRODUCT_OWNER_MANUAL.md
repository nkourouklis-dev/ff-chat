## 1. Το προϊόν σε μία παράγραφο

Το Liakos Chat είναι ιδιωτικό chat για μια συγκεκριμένη παρέα φίλων: real-time μηνύματα,
εφήμερα video 24 ωρών, παιχνίδια και ένας AI χαρακτήρας («ο Λιάκος») που θυμάται τον κάθε
χρήστη. Τρέχει εξ ολοκλήρου στο Cloudflare free tier. Το διαφοροποιητικό δεν είναι το chat —
είναι ο Λιάκος ως **μέλος** της παρέας, με μακροχρόνια μνήμη ανά άτομο.

**Ο χρήστης-στόχος** δεν είναι developer. Δεν έχει κωδικό, δεν έχει email, δεν κατεβάζει app.
Ανοίγει link, γράφει όνομα, είναι μέσα. Κάθε απόφαση προϊόντος περνάει από αυτό το φίλτρο.

## 3. Ρίσκα — κατά σειρά σοβαρότητας

### 🔴 R1 — Ο χρήστης δεν μπορεί να ξαναμπεί στον λογαριασμό του
**Πού:** `worker/index.ts`, `POST /api/auth/login`.
Το endpoint κάνει **πάντα** `INSERT INTO users` με νέο UUID. Δεν ψάχνει ποτέ υπάρχοντα
χρήστη. Το token ζει 365 μέρες στο `localStorage`, οπότε στην πράξη δεν φαίνεται — μέχρι
κάποιος να πατήσει «Έξοδος», να καθαρίσει τον browser, ή να αλλάξει συσκευή.

**Επίπτωση:** χάνει δωμάτια, ιστορικό και όλη τη μνήμη του Λιάκου. Μη αναστρέψιμο.
**Πιθανότητα:** βέβαιη — το κουμπί «Έξοδος» είναι ορατό στη λίστα Chat.
**Ελάχιστη μείωση (σήμερα, 5 λεπτά):** βγάλε το κουμπί «Έξοδος» ή βάλ' του `confirm()` με
προειδοποίηση.
**Σωστή λύση:** 4-ψήφιο PIN ή magic link με email. Έχει σχεδιαστικό κόστος γιατί χαλάει το
«μόνο όνομα» — γι' αυτό είναι απόφαση δική σου, όχι τεχνική.

### 🔴 R2 — Μηδέν rate limiting
Τα `/api/media` (upload στο R2) και `/api/ai/chat` (2 κλήσεις AI) είναι ανοιχτά σε κάθε
έγκυρο token. Ένα απλό script γεμίζει το R2 ή καίει το AI quota. Και το token το παίρνει
οποιοσδήποτε με ένα POST χωρίς κανέναν έλεγχο.

**Λύση:** Durable Object counter ή Cloudflare Rate Limiting rules. Ξεχωριστό όριο ανά
endpoint: media π.χ. 20/ώρα, ai π.χ. 60/ώρα.

### 🟠 R3 — Τα αρχεία δεν σβήνονται ποτέ από το R2
Τα `updates` λήγουν στη **βάση** (`expires_at`), αλλά το αντικείμενο στο R2 μένει για πάντα.
Το ίδιο και όταν σβήνεται δωμάτιο: το `DELETE /api/rooms/:id` σβήνει τα `messages` αλλά όχι
τα media τους. Το R2 γεμίζει μονόδρομα προς τα 10 GB.

**Λύση:** Cron Trigger (`[triggers] crons = ["0 3 * * *"]`) που κάθε βράδυ διαβάζει ληγμένα
`updates`/`messages`, σβήνει τα R2 objects, μετά τις εγγραφές.

### 🟠 R4 — Το polling των badges καίει το Workers quota
`useUnread` ρωτάει κάθε 12 δευτερόλεπτα ενώ το app είναι ορατό. 10 άτομα × 16 ώρες
≈ 48.000 requests/μέρα, μόνο για badges — σχεδόν όλο το ημερήσιο δωρεάν όριο των 100.000.

**Λύση:** ανέβασε το interval σε 30–45s **ή** στείλε τα unread counts μέσα από το WebSocket
του δωματίου, ώστε να μη χρειάζεται καθόλου polling όσο είσαι μέσα.

### 🟠 R5 — Το Feed είναι καθολικό, όχι ανά δωμάτιο
Το `GET /api/updates` επιστρέφει **όλα** τα ενεργά updates κάθε χρήστη της εφαρμογής,
χωρίς φίλτρο δωματίου ή μέλους. Όποιος έχει λογαριασμό βλέπει τα video όλων.

Για μία παρέα ίσως είναι το επιθυμητό. Αν όμως μπει δεύτερη παρέα, είναι διαρροή.
**Απόφαση που πρέπει να πάρεις πριν το ανοίξεις σε δεύτερο κύκλο.**

### 🟡 R6 — Το media endpoint είναι δημόσιο
Το `GET /api/media/:userId/:file` δεν έχει `requireSession`. Όποιος έχει το URL κατεβάζει το
video χωρίς λογαριασμό. Τα keys είναι UUID (δύσκολο να τα μαντέψεις), αλλά ένα URL που
διέρρευσε μένει ανοιχτό για πάντα. Είναι συνειδητός συμβιβασμός για να δουλεύει το
`<video src>` — αν το κλειδώσεις, θέλεις signed URLs.

### 🟡 R7 — Token στο query string του WebSocket
Το `openRoomSocket` βάζει `?token=...` στο URL. Τα URLs καταγράφονται σε proxies και logs
πιο εύκολα από τα headers. Οι browsers δεν επιτρέπουν custom headers σε WebSocket, οπότε
η εναλλακτική είναι short-lived ticket: ζητάς ένα token 30 δευτερολέπτων από REST και το
χρησιμοποιείς μόνο για το upgrade.

### 🟡 R8 — Καμία moderation
Ανεβαίνουν video, ορατά σε όλους, χωρίς report και χωρίς δυνατότητα διαγραφής από
διαχειριστή. Σε παρέα φίλων δεν είναι θέμα. Την ημέρα που μπει άγνωστος, γίνεται.

## 4. Roadmap

### Φάση 1 — Σταθεροποίηση (πριν από οτιδήποτε άλλο)
Στόχος: να μη χάνει κανείς δεδομένα και να μη σκάει το free tier.

1. Επιδιόρθωση/απόκρυψη του «Έξοδος» *(R1)* — **1 ώρα**
2. Rate limiting σε media + ai *(R2)* — **μισή μέρα**
3. Cron καθαρισμού R2 *(R3)* — **μισή μέρα**
4. Polling 12s → 30s *(R4)* — **10 λεπτά**
5. Icons στο manifest — **20 λεπτά**

### Φάση 2 — Τα φθηνά κέρδη
Ο server τα υποστηρίζει ήδη. Είναι **μόνο frontend**.

6. **Typing indicator** — το `typing` event υπάρχε στο DO, αχρησιμοποίητο. Μεγάλο αίσθημα
   «ζωντάνιας» για ~2 ώρες δουλειάς. *Καλύτερος λόγος αξίας/κόπου σε όλο το backlog.*
7. **Multiplayer τρίλιζα** — το `game` event υπάρχει, ο πίνακας `game_sessions` υπάρχει άδειος.
8. **Presence ανά άτομο** — dedupe με βάση το `userId` στο `broadcastPresence`, ώστε δύο
   καρτέλες του ίδιου ανθρώπου να μετράνε 1.
9. **Read receipts** — ο πίνακας `room_reads` έχει ήδη τα δεδομένα.

### Φάση 3 — Πραγματικά νέα δυνατότητα
10. **Push notifications (Web Push)** — αυτό είναι που κάνει την εφαρμογή να χρησιμοποιείται
    καθημερινά αντί περιστασιακά. Στο iOS δουλεύει μόνο ως εγκατεστημένο PWA.
11. **Video στα μηνύματα** — ο τύπος `media` υπάρχει στο schema και το Room κάνει render
    `<video>`, αλλά δεν υπάρχει κουμπί για να στείλεις video μέσα σε chat.
12. **Ο Λιάκος στο group chat** με `@liakos` — μεγάλη διαφοροποίηση.
13. **Feed ανά δωμάτιο** *(R5)*.

### Φάση 4 — Φιλόδοξα
14. Κλήσεις φωνής/video με Cloudflare Calls (WebRTC SFU).
15. **Εβδομαδιαίο highlight reel:** ο Λιάκος συνθέτει αυτόματα τα updates της εβδομάδας με
    λεζάντες και αφήγηση. Ο Λιάκος γίνεται ο χρονικογράφος της παρέας — αυτό είναι το
    πραγματικά μοναδικό, όχι το chat.

## 5. Πώς αποφασίζω τι μπαίνει

**Ερώτηση 1:** Χάνει κάποιος δεδομένα ή σκάει το free tier; → Φάση 1, τώρα.
**Ερώτηση 2:** Ο server το υποστηρίζει ήδη; → φθηνό, προτεραιότητα.
**Ερώτηση 3:** Χρειάζεται ο χρήστης εξήγηση για να το χρησιμοποιήσει; → αν ναι, ξανασχεδίασέ το.
**Ερώτηση 4:** Το θα χρησιμοποιούσε η παρέα την επόμενη εβδομάδα; → αν όχι, μπαίνει στο ράφι.

**Definition of Done** για κάθε αλλαγή:
- [ ] Δουλεύει τοπικά με δύο διαφορετικούς χρήστες σε δύο tabs
- [ ] Δουλεύει σε πραγματικό κινητό (όχι μόνο σε responsive mode)
- [ ] Δεν σπάει το `/health`
- [ ] Νέο migration αν άλλαξε schema, εφαρμοσμένο **local και remote**
- [ ] Ο χρήστης καταλαβαίνει τι έγινε χωρίς οδηγίες
- [ ] Ενημερώθηκε το `03_USER_MANUAL.md` αν άλλαξε κάτι ορατό
- [ ] Νέο git tag

## 6. Διαδικασία έκδοσης

```
τοπικό dev (2 τερματικά)
   ↓  npm run worker:dev  +  npm run dev
δοκιμή με 2 tabs, 2 ονόματα
   ↓  wrangler d1 migrations apply liakos_db --remote   (αν άλλαξε schema)
git commit + git tag vX.Y.Z
   ↓  git push origin main --tags
GitHub Actions → Worker + Pages αυτόματα
   ↓
δοκιμή στο production από κινητό
```

**Semantic versioning όπως το εφαρμόζεις ήδη:**
`v1.0.0` MVP → `v1.1.0` AI memory → `v1.2.0` unread badges → `v1.3.0` edit/delete.
Minor για νέα δυνατότητα, patch για διόρθωση, major όταν σπάει κάτι για τον χρήστη.

**Rollback:** `git revert` + push. Το D1 **δεν** κάνει rollback — γι' αυτό τα migrations πρέπει
να είναι πάντα additive (`ADD COLUMN`, νέος πίνακας), ποτέ `DROP COLUMN`.

## 7. Δείκτες που αξίζει να μετράς

Αυτή τη στιγμή δεν μετράς **τίποτα**. Πριν προσθέσεις δυνατότητα, βάλε τουλάχιστον αυτά —
αλλιώς χτίζεις στα τυφλά:

| Δείκτης | Πώς το βρίσκεις σήμερα |
|---|---|
| Ενεργοί χρήστες / εβδομάδα | `SELECT COUNT(DISTINCT user_id) FROM messages WHERE created_at > ...` |
| Μηνύματα ανά μέρα | `SELECT COUNT(*) FROM messages GROUP BY date` |
| Ενεργά δωμάτια | δωμάτια με μήνυμα τις τελευταίες 7 μέρες |
| Χρήση Λιάκου | δεν καταγράφεται πουθενά — **πρόσθεσε πίνακα `ai_usage`** |
| Updates ανά εβδομάδα | `SELECT COUNT(*) FROM updates` |
| Μέγεθος R2 | Cloudflare Dashboard → R2 |
| Χρήση Workers quota | Cloudflare Dashboard → Workers → Metrics |

**Ο ένας δείκτης που μετράει πραγματικά:** πόσα άτομα έστειλαν μήνυμα σε 7 από τις
τελευταίες 7 μέρες. Αν είναι 0, καμία νέα δυνατότητα δεν θα το αλλάξει — το πρόβλημα είναι
οι ειδοποιήσεις (Φάση 3).

## 8. Κόστος

Σήμερα: **0 €**. Όλα στο Cloudflare free tier.

Τι θα σε βγάλει από το δωρεάν, με σειρά πιθανότητας:
1. Workers requests (το polling — R4)
2. R2 storage (τα video που δεν σβήνονται — R3)
3. Workers AI neurons (αν ο Λιάκος γίνει δημοφιλής)
4. D1 writes (κάθε μήνυμα είναι ένα write)

Το Workers Paid είναι $5/μήνα και ανεβάζει δραματικά όλα τα όρια. Για παρέα φίλων δεν θα
χρειαστεί, εφόσον γίνουν οι διορθώσεις της Φάσης 1.
